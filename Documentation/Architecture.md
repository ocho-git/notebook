# Architecture and extraction

The implementation was extracted from Zen Garden's FieldGuide sources on 5 November 2026. The source app remains unchanged and is not yet migrated to this package. This is a standalone reusable engine, not an automatic shared dependency of Zen Garden.

- `Notebook.swift`: public document/leaf/page/cover/lighting models and SwiftUI wrapper.
- `NotebookController.swift`: main-actor state, gestures, layout, texture loading and lifetime.
- `BookRenderer.swift`: SceneKit scene, per-frame spring animation, shadow/light and sound feed.
- `BookGeometry.swift`: page curves, rolling folds, page stacks, spine and mesh construction.
- `BookMaterials.swift`: procedural leather, paper edges, shadow materials and per-instance cover lettering.
- `BookSounds.swift`: procedural audio with an atomic render-thread-to-audio-thread feed.
- `BookSpring.swift`: portable spring integration.

The renderer takes a locked snapshot of controller inputs each frame. Scene geometry is updated on SceneKit's render thread; events return to the main actor. Page snapshots are rendered on the main actor and mipmapped before installation. Nearby faces are loaded on demand; offscreen textures are evicted. At rest, continuous drawing stops. Dismantling the view cancels pending work and pauses its audio engine.

The physical dimensions and animation tuning remain internal to preserve the original book's behavior. Cover title, spine title and leather/foil color are instance-specific. The original Japanese field-guide lettering, catalog, sketches, discovery state, bird recordings, close-up UI, handwritten keeper name, custom fonts and CloudKit integration belong to Zen Garden and are intentionally not bundled. Hosts can render their own content and implement editing or detail UI around the public page/tap API.

There are no bundled third-party assets or dependencies. All included textures and sounds are generated by source code. System fonts are resolved at runtime. `macOS` availability in the manifest supports tests of portable geometry/audio only; book presentation uses UIKit and remains guarded by `os(iOS)`.
